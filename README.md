# Adventure TV

Adventure TV is a synchronized 24/7 adventure channel built around adventures from across the globe: hiking, camping, hunting, sightseeing, treasure hunting, gemstones, gold and silver prospecting, mining, and exceptional scenery.

## Channel behavior

- Uses the same live-style scaffold as the other Infinity TV channels.
- Joins the currently scheduled program at the correct station-clock position.
- Keeps the current day stable when the viewer refreshes.
- Builds a new deterministic lineup at 12:00 AM in the viewer's local time.
- Uses full or long-form public embeddable programs as the scheduled source material instead of trailers or short promotional clips.
- Holds unused portions of a time slot as an Adventure TV intermission so the next program still begins on schedule.
- Includes Start over, Rewind 30 sec, Join live, Share/StarCoin progress, wallet count, a 24-hour guide, and an expandable seven-day guide.
- Includes the shared-style hamburger channel remote and lower channel directory.
